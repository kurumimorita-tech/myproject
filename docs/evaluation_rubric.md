# ロープレ合否判定ルーブリック（研修生シート準拠）

研修生シートの評価項目を、**ロープレ（音声/テキスト対話）で判定できるもの**と
**現場でしか目視確認できないもの**に整理したもの。アプリのフィードバック機能は
この「判定可能」項目を `◎達成 / △一部 / ✕未達 / -該当なし` で自動採点する。

判定は `◎=しっかりできている` `△=やろうとしたが不十分` `✕=できていない`
`-=今回の顧客設定・流れでは該当しない` の4段階。

---

## A. ロープレで判定可能（自動採点対象）

### A-1. 基本接客・スタンス
| 項目 | 判定の観点 |
|---|---|
| 言葉遣い | 敬語・適切な表現でお客様/代理店と話せているか |
| 会話のきっかけ作り | つかみ・声かけで足を止め、会話に入れているか |
| 相手に合わせた話し方 | 相槌・スピード・声量・トーンの調整（音声のみ部分評価） |
| 家族・子連れ対応 | 同行者全員への配慮／決裁者（親）が集中できる環境作り |

### A-2. ヒアリング（アンケート）
| 項目 | 聞き出すべき内容 |
|---|---|
| 携帯の必要情報 | 料金・通信量・名義・決裁者・使用台数・機種種別・かけ放題 |
| マイページ確認 | 画面共有の依頼→具体的な利用状況（データ量・料金明細）の把握 |
| 光回線の必要情報 | 会社・期間・名義・料金・固定電話・テレビ |
| でんきの必要情報 | 会社・プラン・期間・名義・オール電化・太陽光 |
| 学生利用 | 家族構成・年齢構成（5〜18歳の有無）・端末ニーズ |
| 乗り換え需要 | 現契約の不満点・過去の乗り換え経験・希望特典 |
| 本人確認書類の所持確認 | 免許/マイナ等の所持確認（外国籍は在留カード・在留期限） |
| 情報の整理 | 聞き出した要素を整理し、提案内容を組み立てられているか |

### A-3. ニーズ把握・興味付け
| 項目 | 判定の観点 |
|---|---|
| 料金ニーズ | 料金の不満・要望を読み取り興味付け |
| 端末ニーズ | 使い方・不満から端末買い替えの興味付け |
| キャッシュバックニーズ | CBの希望内容・金額を把握し興味付け |
| 限定感ニーズ | イベント限定感を使った興味付け |
| 学割・季節・話題性ニーズ | 学割/季節/新プラン等の話題での興味付け |
| 決裁者の見極め | 決裁者を特定し、決裁者に向けて興味付け |

### A-4. クロージング
| 項目 | 判定の観点 |
|---|---|
| テストクロージング | 温度感の確認・ボトルネックの洗い出しを適宜行えたか |
| ダブルクローザーを呼ぶ判断 | 呼ぶ必要性とタイミングを理解し、違和感なく呼べたか |
| 名義人/決裁者の手配 | 本人/館内呼び出し/後日再来 等、パターンに応じてクリアできたか |
| 見積の説明 | 初月・2ヶ月目以降、プラン変更・オプション見直しを納得させられたか |
| MNP予約番号の知識 | 発行可否ブランド、電話/WEBの切り分けを説明できたか |
| 引継ぎ | 名義・支払い・還元／データ移行・メアド・端末利用可否・SIMロック・APN |

### 総合判定（合格ゲート）
以下を**すべて満たせば「合格」**、いずれか欠ければ「不合格（惜しい/要再挑戦）」：
1. 隠れたニーズを見抜き、それに刺さるクロージングができている
2. 名義人/決裁者の同席・手配条件をクリアしている
3. 契約に必要な主要情報のヒアリングができている

## B. ロープレでは判定不可（現場で目視確認）

会話だけでは確認できないため、フィードバックでは「現場確認項目」として明示のみ行う。

- 協業事業の理解（代理店・他社人員・役回り）
- 館ルール／入退館／キャッチ範囲
- 個人情報の照会・端末操作の実行
- 身だしなみ（髪型・服装・爪・靴）
- 挨拶・姿勢・立ち居振る舞い（片足立ちしない 等）
- インカムの基本操作（送受信・グループ設定）
- サンプリング（ティッシュ等の物理配布）
- ブースへの物理的誘導・クローザーへのスイング
- POP付きのお客様の発見・声かけ
- イベントコンテンツ（BINGO・握力 等）への順応・盛り上げ
- 臨機応変なキャッチ層の調整
- ジニー操作（料金シミュレーター・固定料金）
- エリア検索（光/Air/テレビ/固定電話の提供可否）
- マルチ顧客照会（既存利用状況・本確提示・タブ消し）
- 接客ナビからの重要事項説明動画の案内
- 本人確認書類の**目視**確認
- MNP予約番号の**実発行**
