# Closer Mind Master（仮）— 設計書

クローザー（人材派遣の営業スタッフ）が **現場で失注してもうろたえないタフなメンタル** を鍛えるための、
格闘ゲーム／RPG戦闘風「1問1答マインドバトル」アプリ。

- **目的1：** 断られてもブレない「タフマインド」の形成
- **目的2：** クロージングを「楽しいゲーム」と脳に錯覚させる潜在意識の書き換え
- **ターゲット：** 人材派遣会社のクローザー（営業スタッフ）
- **形態：** スマホ **横画面** で遊ぶ、依存ライブラリなしの単一HTML（`closer-mind-master.html`）

---

## 1. ゲームフロー（開始 → クリア）

```
┌────────────┐
│ ① タイトル │  「Closer Mind Master」ロゴ ＋ [▶ バトル開始]
└─────┬──────┘  横画面推奨のガイドを表示
      │
      ▼
┌────────────┐
│ ② ステージ │  対戦相手（NPC顧客）の紹介カード
│   選択      │  例）Lv1「予算しぶり課長」 Lv2「他社ラブ担当」 Lv3「決裁引き伸ばし部長」
└─────┬──────┘
      │
      ▼
┌───────────────────────────────────────────────┐
│ ③ バトル（メイン画面）                          │
│                                                 │
│  ・顧客が拒絶文句を放つ（「お金がない」等）      │
│  ・営業は 3〜4 択から回答を1つ選ぶ              │
│                                                 │
│   選択の結果でパラメータが変動：                 │
│   ┌─────────────┬──────────────────────────┐   │
│   │ ◎ 刺さる回答 │ 温度感メーター ↑↑（+大）  │   │
│   │ ○ 悪くない   │ 温度感メーター ↑（+小）    │   │
│   │ △ ブレ回答   │ メンタルHP ↓（うろたえ）  │   │
│   │ ✕ 地雷回答   │ メンタルHP ↓↓＋温度 ↓     │   │
│   └─────────────┴──────────────────────────┘   │
│                                                 │
│  ・顧客の表情が％で変化：冷酷 → 悩む → 笑顔     │
│  ・コンボ（連続で刺さると加点ボーナス）          │
└───────┬──────────────────────────┬──────────────┘
        │ 温度感 100%                │ メンタルHP 0
        ▼                            ▼
┌────────────────┐          ┌────────────────────────┐
│ ④ 成約(クリア) │          │ ⑤ ゲームオーバー        │
│ 「契約成立！」  │          │ 失注。ただし名言が出る： │
│ 花火・SE・評価  │          │ 「失注は成功へのプロセス」│
│ [次のステージ]  │          │ [▶ すぐリトライ]         │
└────────────────┘          └────────────────────────┘
```

### ステート遷移
`TITLE → STAGE_SELECT → BATTLE → (WIN | LOSE) → STAGE_SELECT/BATTLE`

- **WIN 条件：** 温度感メーターが 100% に到達
- **LOSE 条件：** メンタルHP が 0 に到達
- **リトライ：** LOSE 後は即同ステージへ（失注＝プロセスというポジティブ設計）

### 表情の段階（温度感メーターに連動）
| 温度感 | 状態 | 表情 |
|---|---|---|
| 0–33%   | 冷酷・警戒 | 😠 / 😒 |
| 34–66%  | 悩む・迷い | 🤔 / 😐 |
| 67–99%  | 前向き     | 🙂 |
| 100%    | 成約・笑顔 | 😄🤝 |

### UI/UXのこだわり
- **格ゲー/RPG風**：上部にメーターとHPゲージ、下部にコマンド（選択肢）を配置。
- **フィードバックの即時性**：選択→数字ポップ／シェイク／SE／メーター増減を同時発火し「気持ちよさ」を演出。
- **コンボ**：連続で◎を出すと `COMBO xN` 表示＋加点ボーナスで爽快感。
- **ポジティブ・ループ**：失注しても名言＋即リトライで「怖くない・また挑戦したい」体験に。
- **横画面固定**：縦持ち時は「横にしてね」ガイドを表示。

## 3. プロトタイプ実装

- 実体：リポジトリ直下の **`closer-mind-master.html`**（単一ファイル・依存なし）。
- 選択肢クリックで温度感メーター／メンタルHPが変動するロジックを実装済み。
- 顧客セリフ・選択肢・効果量はファイル冒頭の `STAGES` データで定義（差し替え・追加が容易）。
- Web Audio API による簡易効果音（外部アセット不要）。

### 拡張の方向性（次フェーズ）
- ステージ／セリフの外部JSON化、既存の音声ロープレ（`index.html`）との連携。
- AIによる自由入力採点モードへの接続（本リポジトリの評価ルーブリック流用）。
- スコア・称号・ランキング、日替わりチャレンジ等のリテンション施策。
