# 通信回線 切り替え営業ロープレ（音声対話トレーニング）

イベントブースでの通信回線（携帯・ネット・電気）切り替え営業を、**音声で**練習できるWebアプリです。
AIが一般のお客様になりきり、裏設定（名義人の所在・現在の契約・隠れたニーズ・アウト返し）に基づいてリアルに反応します。

## 使い方

1. `index.html` をブラウザで開く（**Google Chrome 推奨** ／ 音声入力に必要）。
2. **AI提供元** を選び、**APIキー** を入力。
   - **Google Gemini（無料・カード登録不要／推奨）**：[aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey) で無料取得
   - **Claude（Anthropic・有料）**：[console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys) で取得（要カード登録）
   - キーはブラウザ内（localStorage）にのみ保存され、選んだAI提供元以外には送信されません。
3. **「▶ ロープレ開始」** を押すと、ブースで見えるお客様情報（年齢・性別／同伴者）が表示されます。
4. **🎤マイク** または テキスト入力で営業トークを開始。お客様が**声で**返答します。
5. うまくヒアリング＆クロージングできれば **成約**。
6. **「🏁 フィードバックをもらう」** で指導者視点の振り返り＋裏設定の答え合わせ。
   - 途中で **「🔍 裏設定を見る」** でも答え合わせが可能です。

## 機能

- 🎤 音声認識（Web Speech API, 日本語）で営業トークを入力
- 🔊 音声合成でお客様がリアルに返答（声・自動マイクON切替あり）
- 🆓 AI提供元を選択（**Google Gemini＝無料・カード不要** ／ Claude＝有料）
- 🧠 モデル選択（Gemini Flash / Flash-Lite / Pro、または Sonnet 5 / Opus 4.8 / Haiku 4.5）＋🔄で利用可能モデル取得
- ⏱️ ターン/時間制限（20往復・15分）超過で「時間切れ失注」に自動遷移
- 💡 ヒント機能（指導者がこっそり次の一手を助言。会話履歴は汚さない）
- 🔁 「同じお客様でやり直す」／リセット、🏁 いつでもギブアップして採点
- 🛡️ ガードレール（キャラクターロック・段階的情報開示・脱線/暴言で打ち切り）
- 📊 採点：5項目×2点＝10点スコア＋点数↔合否（成約/保留/失注）の判定ルール、研修生シート準拠の詳細チェックリスト
- 🎭 名義人の所在パターン（本人／館内／不在）に応じた分岐展開
- 🎓 ロープレ後のフィードバックと裏設定の答え合わせ

## 技術メモ

- 追加の依存関係なし。単一の `index.html` で完結。
- ブラウザから直接 Anthropic Messages API を呼び出します
  （`anthropic-dangerous-direct-browser-access` ヘッダを使用）。
- 音声入力は Chromium 系ブラウザで動作します。非対応ブラウザではテキスト入力が使えます。
